# WeatherApp

WeatherApp is a learning project for building a weather application while
exploring REST APIs, Docker, Kubernetes, and microservice architecture.

The planned application will use the [OpenWeather API](https://openweathermap.org/api)
to retrieve weather data. The project will grow incrementally, so the current
implementation is intentionally small and will be expanded as new concepts are
introduced.

## Learning goals

- Build and consume REST APIs.
- Integrate an external API such as OpenWeather.
- Manage API keys and configuration safely.
- Package services with Docker.
- Deploy and operate services with Kubernetes.
- Split application responsibilities into independently deployable
  microservices.
- Practice C++ development with CMake and the Crow web framework.
